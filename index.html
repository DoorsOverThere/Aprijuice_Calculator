The color of the apricorn used to cook an Aprijuice provides riding stat modifiers in addition to any flavor-based bonuses gained from Berries.

Flavor values of the same type are added together and compared against a set of thresholds. When a threshold is reached, a corresponding number of stat points is added to the aprijuice for the riding stat associated with that flavor.
